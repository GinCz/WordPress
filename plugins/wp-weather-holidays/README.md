# WP Weather & Holidays (VladiMIR+AI✅)

Ultra-fast, compact weather informer for 11 European capitals and daily European, Czech, and Russian holidays banner.

## Features
- **11 Capitals Live Weather (`[vb_weather]`):** Prague, Berlin, Paris, Madrid, Rome, Warsaw, Budapest, Athens, Jerusalem, Chisinau, Kyiv.
- **Smart 1-hour Caching:** Free Open-Meteo batch API with zero API keys required and 100% server-side transient caching.
- **Czech Svátek Calendar (`[vb_svatek]`):** Daily official Czech name day highlighting.
- **Name Days (День Ангела):** Daily Orthodox & European saints name days.
- **European & Russian Holidays (`[vb_holidays]`):** Major official, cultural and UN international observances.
- **Combined Widget (`[vb_weather_holidays]`):** Perfectly fits Flatsome sidebars in a sleek 2-column layout.
