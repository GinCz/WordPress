# Changelog — WP Date & Time Micro

## [2026-11__1.00] - 2026-11-17
### Added
- Initial release.
- Lightweight timezone-aware shortcode handler using native `wp_date()`.
- Drop-in aliases: `[wpdts]`, `[wp-dt]`, `[wp_dt]`, `[wpdts-date]`, `[wpdts-time]`, `[wpdts-year]`, etc.
- Support for `format`, `offset`, and `timestamp` shortcode attributes.
