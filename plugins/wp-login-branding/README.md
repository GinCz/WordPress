# WP Login & Admin Branding (VladiMIR+AI✅)

**Ultra-modern turnkey customizer for WordPress authentication pages.**

## Features
- **Turnkey Admin Settings Panel**: Dedicated control center under `Settings -> Брендинг входа` with instant preview.
- **Default Site Logo Detection**: Automatically detects and displays the default site logo from Flatsome (`site_logo`), WP Customizer (`custom_logo`), or site icon, with custom upload and sizing options.
- **Background Presets & Custom Images**: Choose from 6 curated gradients (Cosmic Purple, Deep Ocean, Dark Graphite, Cyber Emerald, Sunset Aurora, Modern Light), custom CSS gradients, or upload custom background images with dark overlays.
- **Visual FX & Entrance Animations**: Smooth Fade In & Slide Up, Zoom In, Neon Pulse Glow, ambient breathing glow, and floating bokeh light orbs.
- **Glassmorphism Form Cards**: Frosted light glass, dark obsidian frost, or classic solid white.
- **Custom Accent Color**: Full color picker for buttons, focus outlines, and atmospheric glow.
- **Modern Inputs & Buttons**: Custom styled inputs with vibrant focus rings and rich gradient action buttons.
- **Social Login Integration**: Perfectly blends miniOrange social login icons into the card.
- **Clean Footer & Link Pills**: Converts default WordPress links into modern floating glass pills and adds brand copyright footer.
- **Admin Bar Dark Accent**: Polishes top admin bar styling.
