# WP Login & Admin Branding (VladiMIR+AI✅)

**Ultra-modern turnkey customizer for WordPress authentication pages.**

## Features
- **Dynamic Site Branding & Country Flags**: Automatically replaces standard WordPress logo with site logo/animated flag (`de.gif`, etc.) and country flags (`🇩🇪`, `🇨🇿`, `🇦🇹`, etc.).
- **Ambient Glow Backdrop**: Deep space-purple canvas with animated glowing radial orbs matching site aesthetic.
- **Glassmorphism Form Card**: Frosted glass card with smooth blur (`backdrop-filter: blur(20px)`), soft shadows, and clean borders.
- **Modern Inputs & Buttons**: Custom styled inputs with vibrant purple focus rings and rich gradient action buttons (`#7c3aed` to `#4c1d95`).
- **Social Login Integration**: Perfectly blends miniOrange social login icons into the card.
- **Clean Footer & Link Pills**: Converts default WordPress links into modern floating glass pills and adds brand copyright footer.
- **Admin Bar Dark Accent**: Polishes top admin bar styling.
